# Employee Management System

A backend Employee Management System built using Java, Spring Boot, MySQL and JPA/Hibernate.

## 🚀 Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Spring Security
- REST API
- Maven

## ✨ Features

- Create Employee
- Get Employee by ID
- Get All Employees
- Update Employee
- Delete Employee
- MySQL Database Integration
- JPA/Hibernate
- Layered Architecture
- RESTful APIs
- Spring Security
